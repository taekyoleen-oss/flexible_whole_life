# 설계형 종신보험 (flexible whole life)

보험금을 구간별로 설계하는 종신보험의 보험료·준비금·해약환급금 엔진과 Next.js 앱.

- 계획서: `docs/tkLeen_설계형종신보험_앱개발계획서.md` (§3.4 엔진 명세, §7 골든값)
- 엔진 구현 계획: `docs/superpowers/plans/2026-09-10-engine.md`

## 명령

```bash
npm test                        # vitest 골든·규칙 테스트
node scripts/extract-rates.mjs  # 위험률표 재추출 (../Python_Web_like_Excel 워크북 필요)
npm run dev                     # Next.js 개발 서버
```

## 화면

| 라우트 | 내용 |
|---|---|
| `/` | 이어서 설계 · 새 설계 · 보관함(이 브라우저에 저장한 설계 목록, JSON 가져오기) · 샘플 3종 |
| `/start` | 고객 정보 한 페이지 입력(피보험자·가족·재무·기존 보장) + 니즈·HLV 추천 카드 + 예산 |
| `/design` | 2열 캔버스: 예산·계약·입력 요약 / 보험금 스케줄 편집기(드래그·키보드·확대)·보험료·검증·환급금 곡선·준비금 표(CSV)·카드 편집·산출 근거 |
| `/compare` | 같은 월 예산으로 평준형 종신·정기+종신 조합·설계형 3안 역산 비교(표 + 겹친 그래프) |
| `/print` | 제안서: 고객용 2쪽 + 설계사용 1쪽(선택). 브라우저 인쇄 → PDF |
| `/s#…` | 공유 링크: 모바일 읽기 전용 + "내 설계로 가져오기" |
| `/settings` | 가정 세트 선택, 이율·사업비·저해지·니즈·설계 제약 숫자 편집, 골든 G1 검산 |

그래프 편집 규칙: 1칸 = 기준보험금 10%, 직전 변경점부터 지난 연수만큼 이동하며 그 칸 수만큼 직전 연도들이 매년 한 칸씩 계단식으로 오르내림(50세 3칸 ↑ = 47·48·49세), 축하금 = 해당 연령 보험금의 10%(여러 나이를 쉼표로 입력). 기준보험금은 1천만원 단위. 저해지 = 납입기간 중 환급금 30%·보험료 20% 인하.

설계 상태는 localStorage(`fwl:design:v1`)에 자동 저장되고, 보관함(`fwl:designs:v1`)에 이름으로 여러 건을 둘 수 있다. Supabase는 사용하지 않는다(백업·이동은 JSON 파일과 공유 링크).

## 엔진 `lib/engine`

UI 무관 순수 함수. 진입점은 `compute`, `compareAtBudget`, `validate`, `buildPreset`, `needs` (`lib/engine/index.ts`).

| 모듈 | 내용 |
|---|---|
| `commutation` | 이중탈퇴(사망+납입면제) 생존자표·계산기수 |
| `schedule` | 구간 카드 ↔ 연도별 보험금 배수 벡터 |
| `premium` | 급부 현가, 월납 보정 N*, 순·기준연납·영업보험료, 부가보험료 분해 |
| `reserve` / `surrender` | 연말 준비금, 해약공제·환급금·환급률 |
| `compute` | 통합 산출(적용·표준기초, 10만원당 반올림, 사업비 흐름, 저해지: 납입기간 중 환급금 30%·보험료 20% 인하) |
| `presets` / `envelope` | 프리셋 6종, 설계 제약 E01~E08 |
| `needs` / `compare` | 니즈·HLV·프리셋 추천, 같은 예산 3안 비교 |

| G2 종신공제 | 59세 남 · 5년납 · 3.5% · 2배(59~64)·축하금 65세 · 써미트 표 | 2,350 | 2,875 |
