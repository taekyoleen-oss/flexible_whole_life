# 프리셋 근거 기반 설계 계획 (2026-09-11)

목표: 프리셋 6종을 "표준 모양"에서 "해당 케이스의 조건을 입력하면 이론·수식으로 필요보장액 곡선을 산정하고, 그 곡선을 설계 규칙(초기 5년 고정·매년 최대 1칸·70세 이후 증액 불가·상한 3배·하한 20%)에 맞춰 보장 스케줄로 만드는" 근거 중심 설계로 바꾼다. 근거는 카드의 "?"에서, 조건은 카드의 "입력" 팝업에서 다루고, 공통 조건(연소득·자녀·배우자·부채·은퇴시기·기존 보장)은 프로필 한 곳에 두어 어느 팝업에서 고쳐도 모두 반영된다.

## 2. 수식

기호: Y 연소득, ρ 생활비 비율(70%), r 할인율(2%), E 자녀 1인 교육·결혼 자금(1억), F 정리자금(3천만), I 독립 연령(25), a(k, r) = (1 − (1+r)^−k)/r.

### 2.1 자녀연령형 — 유족 생활비·교육비 곡선
- 막내 나이 y, t년 후 독립까지 남은 연수 R_t = max(0, I − y − t)
- 생활비_t = Y·ρ·a(R_t, r), 교육비_t = E × (t년 후 아직 독립 전인 자녀 수), 필요액_t = 생활비_t + 교육비_t + F
- target_t = 필요액_t / 필요액_0. 기준보험금 제안 = 필요액_0 − (유동자산 + 기존 보장)
- 근거: 니즈 접근법(needs approach). 독립 뒤에는 생활비·교육비가 0이 되어 정리자금 F만 남는다.

### 2.2 부채상환형 — 대출 잔액 곡선
- 원리금균등: 연 상환액 P = L·i/(1 − (1+i)^−n), 잔액 B_t = L(1+i)^t − P·((1+i)^t − 1)/i
- 원금균등: B_t = L(1 − t/n). 만기일시: B_t = L (t < n), 0 (t ≥ n)
- 필요액_t = B_t + F, target_t = 필요액_t / 필요액_0. 제안 = L + F
- 조건: 잔액 L·만기 n(공통), 금리 i(5%), 상환방식

### 2.3 은퇴증액형 — 은퇴 후 유족 생활비
- 은퇴 전 필요액 N_pre = 니즈(§2.6). 은퇴 시점 배우자 나이 s = 배우자 나이 + (은퇴시기 − 나이), 기대여명 e_s = Σ_k k·p_s + ½ (제7회 경험생명표)
- 은퇴 후 필요액 N_post = 월 생활비 × 12 × a(e_s, r) + F − 은퇴 자산(연금·퇴직금 현가)
- 배수 R = N_post / N_pre. target_t = 1 (은퇴 전), R (은퇴 후). 증액은 은퇴 시점에 도달하도록 앞당겨 매년 1칸씩(§3), 감액(R < 1)은 은퇴 후 매년 1칸씩
- 조건: 은퇴시기(공통), 배우자 유무·나이, 은퇴 후 월 생활비(250만), 은퇴 자산

### 2.4 단체보험보완형 — 보장 공백
- 재직 중 개인 보장 비율 g = max(0, 1 − 단체보험 보험금 / N_pre). 퇴직(은퇴시기) 후 단체보험이 없어져 1.0
- target_t = g (은퇴 전), 1 (은퇴 후). 퇴직 시점에 1.0에 도달하도록 앞당겨 매년 1칸
- 조건: 단체보험 보험금(공통), 은퇴시기(공통), 니즈 입력(공통)

### 2.5 상속준비형 — 상속세 재원
- 순자산 A_0, 증가율 g: A_t = A_0(1+g)^t
- 상속세(t): 과세표준 = A_t − 일괄공제 5억 − 배우자공제(배우자 있으면 max(5억, min(A_t × 1.5/(1.5+자녀 수), 30억))). 세율 10%(1억 이하)·20%(5억, 누진공제 1천만)·30%(10억, 6천만)·40%(30억, 1.6억)·50%(초과, 4.6억). 신고세액공제·금융재산공제 등은 생략(근사)
- target_t = 상속세_t / 상속세_ref, ref = 증액 종료 연령(70세) 시점(그 뒤 증액 불가). 기준보험금 제안 = 상속세_ref. 하한 0.2
- 조건: 순자산, 증가율(3%), 배우자·자녀 수(공통)

### 2.6 평준형 — 니즈·HLV(기존)
- 니즈 = Y·ρ·a(막내 독립까지, r) + E × 자녀 수 + 부채 + F − (기존 보장 + 유동자산). HLV = Y(1 − 자기소비 30%)·a(은퇴까지, r)
- 조건: 연소득·유동자산·기존 보장(공통)

## 3. 곡선 → 설계 규칙 적합 (`regularizeShape`)
target(t)를 다음 규칙에 맞춘 배수 m(t)로 바꾼다. 원칙: 보장이 필요액 아래로 내려가지 않게(증액은 앞당기고, 감액은 늦춘다).
1. 뒤에서 앞으로 m_t = max(target_t, m_{t+1} − 0.1): 증액을 미리 시작해 필요 시점에 도달(매년 ≤ 1칸)
2. 앞에서 뒤로 m_t = max(m_t, m_{t−1} − 0.1): 감액도 매년 ≤ 1칸(필요액보다 늦게 내려간다)
3. 초기 5년(E01)은 그 구간 최댓값으로 고정하고 2를 다시 적용
4. 증액 종료 연령(E03, 70세) 뒤에는 증액 없음: m_t = min(m_t, m_{t−1})
5. 상한 3배(E04), 하한 max(초기의 20%(E05), 프리셋 하한). 소수 4자리
이 규칙은 그래프 편집 규칙(1칸 = 10%, 직전 변경점 기준 ±칸 수, 매년 ≤ 1칸, 더블클릭 평탄화)과 같은 원칙이며 "설계 규칙" 팝업에 모두 표시한다.

## 4. 프로필 확장(공통 입력)
기존: 성별·연령·배우자·자녀 나이·연소득·유동자산·부채·만기·은퇴시기·단체/정기 보험금. 추가: 배우자 나이(spouseAge), 은퇴 후 월 생활비(livingMonthly), 은퇴 자산(retireAssets), 대출 금리(debtRate), 상환방식(debtMethod), 순자산(netAssets), 자산 증가율(assetGrowth). 어느 팝업에서 고쳐도 한 프로필이므로 중복 입력이 없다.

## 5. 반영 플래그
`InfoApplied = { child, debt, retire, group, estate, income }`. 카드의 "반영" 체크가 켜지면 그 프리셋은 표준 모양 대신 곡선(§2→§3)을 쓴다. 은퇴시기 선택은 은퇴증액형·단체보험보완형이 공유(retire). income은 기준보험금을 입력 기반으로 정했다는 표시.

## 6. UI
- 카드 바닥줄: `[☑ 반영] [입력] [?]` (은퇴증액형·단체보험보완형은 `[은퇴시기 ▾]`가 반영을 겸함, 자녀연령형은 자녀 나이 입력 유지)
- "입력" 팝업: 그 프리셋의 조건(공통 항목은 "(공통)" 표시), 가정값(설정 화면 값) 읽기 전용, 계산된 필요액과 주요 시점 표, "기준보험금으로 적용" 버튼
- "?" 팝업: 근거 문장 + 적용 중이면 계산 수치 요약 + 수식 링크
- 그래프 상단 "설계 규칙" 버튼: E01~E08·1칸·±칸 수·매년 1칸·더블클릭·변경점 정리·프리셋 곡선 규칙을 현재 설정값으로 표시

## 7. 테스트
- finance: 원리금균등 잔액(0년 = L, n년 = 0, 중간 닫힌식), 원금균등·만기일시, 기대여명(남 40세 ≈ 40대 초, 나이 증가 시 감소), 상속세(공제 이하 0, 구간 경계, 배우자 공제), regularize(증액 앞당김·감액 지연·5년 고정·70세 이후 증액 없음·상하한)
- needs 곡선: 자녀 독립 후 F만, 부채 만기 후 F만, 은퇴 R, 단체 g, 상속세 증가
- state: 플래그별 target 반영, 표준 유지, 프로필 새 필드 sanitize
